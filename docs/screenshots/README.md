## Capture output

The capture sample started with six synthetic notes, split between `ingress/local/` and `ingress/dropbox/`. The file modification times supplied their capture timestamps. The actual importer on `main` created immutable files under `entries/` and generated the readable timeline:

```bash
DATA_DIR="/path/to/disposable/demo-data"
./scripts/process_inbox.sh "$DATA_DIR"
cat "$DATA_DIR/notes.txt"
```

The mobile example then added `phone-dictation.txt` and `phone-idea.txt` to `ingress/dropbox/`. Its transcript records the input files and contents, importer exit code, archived inputs, and final timeline entries. This demonstrates the desktop side of the phone workflow; it is not a screenshot of Apple Shortcuts or a live Dropbox transfer.

The example timeline was copied before these two additional notes were imported, so it contains the original six notes. The mobile transcript shows the two subsequent additions.

## Time-use feature output

The analyst examples were generated from a separate synthetic journal covering October 12–18, 2026, in Asia/Kolkata. Eleven notes describe actual deep work, meetings, exercise, or meals; two additional idea/planning notes are excluded by the classifier. The resulting report records 18 hours of observed time and preserves 150 hours as unknown.

The analysis commands below belong to the feature branch, not `main`. The sample ran without an OpenAI key, using the implementation's local heuristic fallback. The report and answers are the actual output, including the report's currently empty “Largest gaps” section and its raw category names in the narrative.

```bash
# In a checkout of feat/events-agents-time-use-mvp:
DATA_DIR="/path/to/disposable/demo-journal"
STATE_DIR="/path/to/disposable/demo-analysis-state"
unset OPENAI_API_KEY OPENAI_MODEL

# Install the feature's partneros command in your development environment.
python3 -m pip install -e partnerOS/eventsAgents

partneros --state-dir "$STATE_DIR" time-use build \
  --data-dir "$DATA_DIR" --week 2026-10-12
partneros --state-dir "$STATE_DIR" time-use report \
  --data-dir "$DATA_DIR" --week 2026-10-12
partneros --state-dir "$STATE_DIR" time-use ask \
  --data-dir "$DATA_DIR" --week 2026-10-12 \
  "Where did my time go last week?"
partneros --state-dir "$STATE_DIR" time-use ask \
  --data-dir "$DATA_DIR" --week 2026-10-12 \
  "How much deep work did I do?"
```

`DATA_DIR` and `STATE_DIR` are aliases for disposable demonstration folders. Keep them separate from real notes. The example files in this directory preserve the output shown in the screenshots; they are documentation samples rather than a complete journal fixture.
